A radar (spider) chart that reads honestly: a common scale from zero that does not move when you filter, axes that stay in place, and gaps where values are missing. The free version compares up to 3 series. Pro adds more series, a target with the gap on every axis, a scale per axis and reversed axes, bands, small multiples, axis groups, annotations, conditional formatting (fx) rules and a value table.

Quick Start

  1. Add Radar & Spider Chart by TCViz to the page. With no fields it shows a start screen with these steps.
  2. Drag the criteria to Axis — quality, price, delivery — and the score to Values, set to Average.
  3. Drag what you compare to Series (legend) — supplier, employee, product.
  4. Or, with survey data in columns, leave Axis empty and drag each question to Values: each measure becomes an axis.
  5. The setup guide in the corner lists the optional fields and the style templates. Pro: add a Target or Small multiples.

How to read it

Read the radar axis by axis: further from the centre is a higher score (or a better one on axes marked ↓). Compare shapes where they cross. The area of a shape depends on the order of the axes, so it is not a total.

Selection and interaction

  • Click a point to filter the rest of the page by its axis and series; click an axis label to select the whole axis, or a legend item to select the whole series. Ctrl/Cmd + click adds; click again or click the background to clear.
  • With a target, the gap per axis is shown for the selected series (always, with one series).
  • Highlight: when another visual filters this one, the highlighted values are drawn over a faded outline.
  • Bookmarks restore the selection. Right-click opens the Power BI context menu. A hierarchy in Axis gives drilldown.
  • When the report author turns interactions off, clicks do not filter.

Accessibility

  • Keyboard: Tab into the visual, arrows move between points, Home/End jump to the first/last, Enter or Space selects, Esc clears, the context-menu key opens the menu. The tooltip opens on the focused point.
  • Each point has a description for screen readers with its series, axis and value; the chart describes its axes and series.
  • High contrast: the visual uses the colours of the Windows contrast theme and tells series apart by line pattern; marker shapes can also differ per series.
  • The layout adapts to the size of the visual: labels wrap or shorten, the legend gives way, ring values and labels are dropped in small panels, and the start screen has three layouts.

FAQ

How do I read a radar chart?

Each spoke is a criterion, and the further a point is from the centre, the higher the score. The shape shows the profile: where a series is strong and where it is weak. Compare shapes axis by axis. The area of a shape depends on the order of the axes, so do not read it as a total — the visual never calculates or shows an area.

Why does the scale start at zero and not move when I filter?

A radar that rescales with every filter makes 57 look like 100. The scale starts at zero by default and you can fix the minimum and maximum (for example 1 to 5) in Format → Scale. Turn off Start at zero only when zero has no meaning for your data.

My axes have different units and some look flat

On a common scale, an axis in ppm or euros flattens axes in % or points, and the visual names it in a note. Options: show the axes in separate visuals, normalise them in DAX, or use Scale → Per axis (Pro), where every axis has its own range and labels its own rings. With Scale minimum / maximum in the field wells, each axis uses the range you give it.

Price or delivery time: lower is better

Type the axis names in Scale → Lower is better (Pro), separated by commas. Those axes are reversed, so outward is always better; they show ↓ next to the name and say so in the tooltip.

Why do some outlines have gaps?

A gap is an empty value. Drawing it as zero would invent a bad score, so the outline stops there. A real zero is drawn.

Why does the axis order change when I filter?

It does not with Data order or Name. With Value of the first series the order follows the values, so it changes with them. To fix any order, use Sort by column on the axis field in the model and keep Data order.

Should Values be Sum or Average?

For scores, use Average. With several evaluations per supplier and criterion, Sum adds them up and the scale no longer means 1 to 5.

I have more than 3 series

The free version draws the first 3 in legend order and the legend says “3 of N series”. Pro draws up to 12. More than 4 or 5 shapes on one radar is hard to read: try small multiples, or One radar per series (Pro).

Conditional formatting (fx) does not colour the markers

Power BI evaluates conditional formatting rules per point only when there is no field in Series, as it does for native charts with a Legend field. Without Series — one shape, or small multiples — the rule colours each marker by its value.

How many rows can it use?

Power BI sends up to 30,000 combinations of axis, series and panel at a time. In the Power BI service the visual asks for further blocks, up to 20 more; in Power BI Desktop it uses the first block. A warning icon in the visual header says when rows were left out.

Do bookmarks keep my settings?

Bookmarks keep the points you select and the filters of the page. Like every Power BI visual, they do not keep formatting.

What is the "Pro preview" watermark?

While you edit a report without a licence, Pro features you turn on are drawn working under a watermark that names them, and Power BI shows its licence notice. Reading view shows the free result, with a small note naming the Pro features it leaves out. Where Power BI provides no licence information (for example when you are not signed in to Power BI Desktop), the free result is shown.

How do I get Pro?

On the visual's Microsoft AppSource page, choose Buy now (not Install free). Licences are per user and managed by Microsoft; restart Power BI Desktop after the licence is assigned. See tcviz.com/licensing.

How are numbers formatted?

With the number format of each measure from the model, dynamic format strings included, in the report's language. Averages that are not whole numbers show up to two decimals when the format has none.

Is my data sent anywhere?

No. The visual makes no network requests and stores nothing outside your report. The links on the start screen open only when you click them, through Power BI.
