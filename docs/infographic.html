Fields

AxisOne spoke per value: criterion, skill, KPI. Without it, each measure in Values is an axis.
ValuesThe score on each axis, usually as Average.
Series (legend)What you compare: supplier, employee, product. Free 3, Pro 12.
+ 6 more: Target (Pro), Scale minimum / maximum (Pro), Axis group (Pro), Note (Pro), Small multiples (Pro), Tooltips

Get started

  1. Install Radar & Spider Chart by TCViz from Microsoft AppSource
  2. Drag the criteria into Axis and the score into Values, set to Average
  3. Drag what you compare into Series (legend): supplier, employee, product
  4. Follow the setup guide in the corner; with Pro, add a Target or Small multiples
